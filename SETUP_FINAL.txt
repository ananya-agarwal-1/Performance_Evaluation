EPMS FINAL - QUICK SETUP

1. Create MySQL database: employee_performance_db
2. Copy backend/.env.example to backend/.env and set your MySQL password + JWT_SECRET.
3. From backend:
   npm install
   npm run import-data
   npm run demo-users
   npm start
4. From frontend:
   npm start
5. Open http://localhost:5500
6. Backend health: http://localhost:3000/api/health
