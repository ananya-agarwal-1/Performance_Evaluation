# EPMS Frontend

The frontend uses plain HTML, CSS, and JavaScript modules with the Fetch API. It has no runtime or build dependencies.

Start the static frontend:

```powershell
npm start
```

Open `http://127.0.0.1:5173/login.html`. The backend must be running at `http://localhost:3000`.

Validate local page links and JavaScript syntax:

```powershell
npm run build
```
